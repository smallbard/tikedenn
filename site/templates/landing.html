Tikedenn

A small kanban board for your development tasks.

Track work from draft to done through six clear states, group tasks by project, and link each task to a git branch to review the diff against main — even for private repositories. No JavaScript framework, no account sprawl: one small Rust server and one SQLite file.

What's inside

  • Six-state kanban — draft, to do, in progress, to review, to deploy, done; move cards by drag & drop or by select.
  • Projects — group your tasks and attach a git repository (with an optional token for private http(s) repos) to each one.
  • Git branches & diffs — any task can point at a branch; the diff against main is rendered file by file in one click.
  • Attachments — files stored next to your tasks (10 MB max each).
  • Self-hosted & boring — one Rust binary, one SQLite file, classic HTML forms. Browse the source on GitHub →
