Setup

  1. Install the CLI from the Tikedenn repository: cargo install --path cli (binary tkd).
  2. tkd login --url {{ base_url }} --token <token>, then tkd install-skill (teaches Claude Code and pi the task protocol).
  3. In the Projects page, set each project's git repository (the worker finds the local clone whose origin matches, under repos_root — default ~/Repos), its base branch and its publish name.
  4. Run tkd worker (options: --agent claude|pi, --max-parallel, --no-deploy). It claims To do tasks, runs an agent in a git worktree per task, and deploys the tasks you approve.
